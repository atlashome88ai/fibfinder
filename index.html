Fib Finder!

Make up a fake answer. Fool your family. Find the truth.

Quick rules

  1. Everyone sees a strange-but-true fact with a word missing.
  2. Type a fake answer that sounds real.
  3. All the answers get mixed up with the real one. Pick the one you think is true.
  4. +2 for finding the truth. +1 for everyone your fib fools!

📖 How to play

The idea

Each round shows a weird-but-true fact with a blank, like "A group of flamingos is called a ___." Everyone secretly types a fake answer. Then all the fakes and the real answer are mixed together, and you try to find the real one while fooling everyone else with your fib.

What you need

  • 3 to 12 players in the same room.
  • One phone or tablet each, with internet.
  • About 2 minutes a question.

Set up

  1. One person hosts. They tap Host the game, type their name and tap Create game. The host plays too.
  2. Everyone else scans the QR code on the host's screen (or taps Join as a player and types the 4-letter code), types their name and taps Join.
  3. The host picks a category (or 🎲 Mix it up) and taps Start game.

Each question

  1. Write a fib. Read the fact, type a fake answer that sounds believable, tap Send my fib. Keep it secret!
  2. If you accidentally type the real answer, the game tells you. Lucky you, but you have to pick something else!
  3. Find the truth. When everyone has sent a fib, all the answers appear on every phone. Tap the one you think is real. (Your own fib isn't shown to you.)
  4. Reveal. When everyone has picked, the answer appears with who wrote each fib and who fell for it.
  5. The host taps Next question. Play as many as you like, then tap Finish game to see the winner.

Points

  • +2 for picking the real answer.
  • +1 for every player who picks your fib.
  • Most points when you finish wins 🏆

Tips

  • The best fibs sound boring and real, not silly.
  • Copy the style: if the blank wants a number, write a number.
  • Kids: a parent can help with spelling. The game doesn't care about capitals.

If something goes wrong

  • "Can't find game": check the 4-letter code on the host's screen.
  • A phone drops out: open the game again; it reconnects by itself.
  • Someone is stuck: the host can tap Skip ahead to move on without them.
  • The host's phone must stay on this game until you finish.
